# Zero-shot, versão 1 (linha de base)

**Técnica:** zero-shot (instrução pura, sem exemplos e sem regras).
**Objetivo:** servir de ponto de partida para medir o ganho das versões seguintes.

## Prompt

```
Leia a conversa abaixo e me diga os avisos importantes.

Conversa:
{{conversa}}
```

## Como usar
Substituir `{{conversa}}` pelo texto de um dos casos da planilha `testes/casos_de_teste.xlsx` e colar a resposta do modelo, sem editar, na aba "Registro de avaliação".
